## النسخة النهائية Polished للإنتاج

**الفورمات:** Influencer يتكلم مباشرة للكاميرا بإيقاع Ping Pong (كل سطر = قطعة مونتاج)
**المدة:** 45-60 ثانية لكل سكريبت
**المنصات:** Reels / TikTok / Snapchat Spotlight / Shorts
**كل سكريبت بنسختين:** خليجية + مصرية

# Script 1: "محدش يعرفهم"

**الزاوية:** السرية | **البنية:** Curiosity > Logic > Reveal > Payoff > CTA
**الترشيح:** يتنشر الأول في الحملة. أعلى احتمال engagement لأن الفضول بيشتغل في الكومنتات لوحده.

## 🇸🇦 النسخة الخليجية

**[Hook | 0-6s]**
```
في شركة سعودية عملاؤها كبار.
مين هم؟
ما راح تعرف.
وسر نجاحها... هنا بالضبط.
```
📱 On-screen: عملاء كبار. أسماء؟ لا.
🎬 Visual: كلوز أب، خلفية داكنة، إضاءة جانبية

**[Build | 6-18s]**
```
ليش السرية؟
فكر فيها ثانية.
شركة تمر بأزمة إعلامية...
وش آخر شيء تبيه؟
إن الناس تعرف إنها طلبت مساعدة.
عشان كذا كل عقودهم تحت NDA.
ما في case study باسم أحد.
ما في شعار على الموقع.
ولا صورة.
```
📱 On-screen: NDA على كل عقد
🎬 Visual: قطعات بين زاويتين، المؤثر يعدد على أصابعه

**[Reveal | 18-32s]**
```
الشركة اسمها جدار.
أول شركة سعودية متخصصة في إدارة الأزمات الإعلامية.
شركات. شخصيات عامة. مؤثرين.
في السعودية والإمارات والخليج كله.
يوم تصير الأزمة، جدار تشتغل بالخفاء.
ويوم تنتهي...
ما أحد دري إنهم كانوا موجودين.
```
📱 On-screen: جدار | يشتغلون بالخفاء
🎬 Visual: قطعة أوسع، ثبات وثقة

**[Payoff | 32-43s]**
```
وهنا النقطة.
الشركة اللي تحمي سمعة عملائها...
تبدأ بحماية أسمائهم.
لو شفت أزمة كبيرة اختفت من الترند فجأة؟
في احتمال...
إن أحد اشتغل عليها بهدوء.
```
📱 On-screen: الأزمات اللي اختفت فجأة... لها قصة
🎬 Visual: الكاميرا تقرب ببطء، نبرة أهدأ

**[Soft CTA | 43-50s]**
```
حاب تعرف كيف يشتغلون من الداخل؟
اكتب (جدار) في التعليقات...
وراح يوصلك التفصيل.
```
📱 On-screen: اكتب: جدار 👇
🎬 Visual: إشارة خفيفة للأسفل، نهاية حادة

# Script 2: "15 دقيقة"

**الزاوية:** السرعة | **البنية:** Night scenario > Agitation > Flip > Ground > CTA
**ملاحظة إخراجية:** أول 18 ثانية إضاءة ليلية خافتة، ومن الـ Flip الإضاءة تفتح تدريجياً. التحول البصري بيدعم التحول النفسي.

## 🇸🇦 النسخة الخليجية

**[Hook | 0-7s]**
```
الساعة 2 الليل.
اسمك ترند.
والكلام كله ضدك.
تتصل بمين؟
بالضبط.
ما عندك رقم.
```
📱 On-screen: 2:00 AM 🔴 اسمك ترند
🎬 Visual: إضاءة ليلية خافتة، وجه قريب، ضوء شاشة جوال على الوجه

**[Agitate | 7-18s]**
```
تفتح X؟ هاشتاق.
تفتح سناب؟ مقاطع.
جوالك؟ ما وقف رنين.
وكل دقيقة تمر بدون رد...
القصة تكبر.
والصمت نفسه يصير خبر.
```
📱 On-screen: الصمت نفسه يصير خبر
🎬 Visual: قطعات سريعة جداً، قطعة لكل منصة

**[Flip | 18-32s]**
```
الحين اقلب الصورة.
نفس الليلة. نفس الترند.
بس هالمرة عندك رقم.
جدار.
فريق طوارئ شغال 24 ساعة.
كم ياخذون عشان يردون؟
15 دقيقة.
بالليل. يوم الجمعة. وقت العيد.
نفس الرقم.
```
📱 On-screen: الرد خلال 15 دقيقة ⏱️
🎬 Visual: الإضاءة تفتح، الإيقاع يثبت، ثقة

**[Ground | 32-43s]**
```
ومن أول ربع ساعة يبدأ الشغل.
تقييم الوضع.
صياغة أول رد.
وإيقاف النزيف قبل ما ينتشر.
الفرق بين أزمة يوم وأزمة شهر؟
غالباً... أول ساعة.
```
📱 On-screen: أول ساعة تحدد كل شيء
🎬 Visual: قطعة لكل خطوة، نبرة حاسمة

**[Soft CTA | 43-50s]**
```
هالفيديو ما تحتاجه اليوم.
تحتاجه في أسوأ ليلة.
احفظه من الحين...
عشان يوم تجي، يكون عندك.
```
📱 On-screen: احفظ الفيديو 🔖 قبل ما تحتاجه
🎬 Visual: كلوز أب هادي، نهاية بدون موسيقى عالية

## 🇪🇬 النسخة المصرية

# Script 3: "اختبار الجاهزية"

**الزاوية:** الانكشاف الشخصي عبر اختبار ذاتي | **البنية:** Challenge > 3 Questions > Diagnosis > Solution > CTA
**ملاحظة:** ده السكريبت الأقرب للـ conversion المباشر. الـ CTA بتاعه واتساب لأن المشاهد اللي وصل للآخر وعدى الاختبار بالفشل بقى warm lead فعلياً.

## 🇸🇦 النسخة الخليجية

**[Hook | 0-6s]**
```
3 أسئلة.
لو جاوبت (لا) على واحد منها...
عندك مشكلة ما تدري عنها.
```
📱 On-screen: 3 أسئلة. جاوب بصدق.
🎬 Visual: مواجهة مباشرة، ثبات كامل، خلفية نظيفة

**[The Test | 6-22s]**
```
سؤال 1:
لو طلع عنك خبر غلط الحين...
مين أول شخص تتصل فيه؟
ما تدري؟ طيب.
سؤال 2:
عندك بيان جاهز لأسوأ سيناريو في مجالك؟
لا؟ كمّل.
سؤال 3:
تدري وش انكتب عنك آخر 30 يوم؟
كل اللي انكتب؟
غالباً لا.
```
📱 On-screen (متتابعة): مين تتصل فيه؟ / وين البيان؟ / وش انكتب عنك؟
🎬 Visual: رقم كبير يظهر مع كل سؤال، قطعة لكل سؤال

**[Diagnosis | 22-35s]**
```
جاوبت (لا) ولو مرة؟
أنت مثل أغلب الشركات والمؤثرين.
ماشي بدون خطة.
والأزمة ما تستأذن.
سكرينشوت قديم.
تصريح ينفهم غلط.
موظف سابق.
أي شرارة تكفي.
```
📱 On-screen: الأزمة ما تستأذن
🎬 Visual: إيقاع أسرع، قطعة لكل شرارة

**[Solution | 35-47s]**
```
جدار، شركة سعودية متخصصة في إدارة الأزمات الإعلامية...
عندهم شيء اسمه تقييم الجاهزية.
يراجعون وضعك الإعلامي.
يحددون نقاط الضعف.
ويقولون لك وين مكشوف بالضبط.
والتقييم الأول؟
مجاني.
```
📱 On-screen: تقييم جاهزية مجاني ✅
🎬 Visual: نبرة تهدأ، ثقة، الحل واضح

**[Soft CTA | 47-55s]**
```
أرسل كلمة (جاهز) على واتساب جدار.
الرقم في التعليق المثبت.
أفضل وقت تكتشف فيه ثغراتك...
قبل ما يكتشفها غيرك.
```
📱 On-screen: أرسل: جاهز 📲 الرقم بالتعليق المثبت
🎬 Visual: كلوز أب أخير، جملة الختام بنبرة هادية

# Script 4: "أول 60 دقيقة"

**الزاوية:** الآلية خلف الكواليس (Process Reveal) | **البنية:** Timeline hook > The Machine > The Network > Reveal > CTA
**تعديل جوهري في الـ polish:** بيت الشبكة اتعاد صياغته بالكامل. الصياغة القديمة كانت توحي بتوجيه خفي للرأي العام، وده خطر سمعة على جدار نفسها. الصياغة الجديدة بتحافظ على الإبهار وبتوصف شغل مشروع: إيصال التوضيح الرسمي والحقائق لجمهور أوسع.

## 🇸🇦 النسخة الخليجية

**[Hook | 0-6s]**
```
وش يصير خلف الكواليس...
في أول 60 دقيقة من أي أزمة إعلامية كبيرة؟
خلني أوريك.
```
📱 On-screen: أول 60 دقيقة من الأزمة ⏱️
🎬 Visual: المؤثر يمشي باتجاه الكاميرا، حركة وطاقة

**[The Machine | 6-24s]**
```
الدقيقة صفر:
أنظمة الرصد تلتقط الإشارة.
قبل ما تصير ترند أصلاً.
الدقيقة 15:
غرفة العمليات مجتمعة.
إعلاميين. قانونيين. محللين.
الدقيقة 30:
أول رد جاهز.
مدروس. محسوب بالكلمة.
الدقيقة 45:
الرسالة توصل للقنوات الصح.
بالترتيب الصح.
```
📱 On-screen (تظهر كـ timeline): د0: رصد / د15: غرفة عمليات / د30: أول رد / د45: انتشار
🎬 Visual: قطعة لكل دقيقة، كاونتر يظهر على الشاشة

**[The Network | 24-38s]**

```
وهنا الجزء اللي ما أحد ينتبه له.

مهمتهم؟
إيصال التوضيح الرسمي...
لأوسع جمهور، بأسرع وقت.
الإشاعة تطلع سريعة.
بس الحقيقة، لما يكون وراها شبكة...
توصل أسرع.
```
📱 On-screen: الحقيقة توصل أسرع لما وراها شبكة
🎬 Visual: نبرة أهدأ وأعمق، كلوز أب

**[Reveal | 38-48s]**
```
هذي آلية جدار.
أول شركة سعودية متخصصة في إدارة الأزمات الإعلامية.
تشتغل في السعودية والخليج كله.
والعملاء؟
سريين. دايماً.
```
📱 On-screen: جدار | هكذا تُدار الأزمات
🎬 Visual: قطعة أخيرة ثابتة، ثقة كاملة

**[Soft CTA | 48-55s]**
```
في تفاصيل أعمق عن كل مرحلة...
بس ما تنقال هنا.
اكتب (الكواليس) في التعليقات...
ولك خبر.
```
📱 On-screen: اكتب: الكواليس 👇
🎬 Visual: نصف ابتسامة، نهاية سريعة

# ملاحظات الإنتاج والتشغيل

## قواعد المونتاج (Ping Pong)
- كل سطر في السكريبت = قطعة مونتاج مستقلة
- تنويع بين زاويتين أو ثلاث زوايا لنفس المؤثر (frontal / 30 درجة / أوسع)
- Zoom punch خفيف (5-10%) مع الجمل القصيرة الحادة
- الجمل اللي قبل الـ payoff تاخد pause نص ثانية قبل القطعة الجاية

## قواعد الصوت
- بدون موسيقى في أول 3 ثواني (الصوت البشري وحده أقوى في إيقاف الـ scroll)
- موسيقى خافتة تدخل من الـ beat الثاني وتعلى تدريجياً
- في سكريبت 2: صوت نوتيفيكيشنز خافت في بيت الـ Agitate

## قواعد الـ On-screen Text
- الأرقام دايماً على الشاشة (15 دقيقة، 60 دقيقة، 3 أسئلة)
- كل نص يظهر متزامن مع نطقه، بدون تقديم
- الكلمة المفتاحية للـ CTA (جدار / الكواليس / جاهز) تفضل ثابتة على الشاشة آخر 5 ثواني

## تجهيزات الـ Funnel قبل النشر (إلزامي)
1. **Auto-reply automation** على كلمات: جدار، الكواليس (ManyChat أو n8n) ترد برسالة فيها رابط الموقع أو رقم الواتساب
2. **رقم واتساب جدار مثبت في أول تعليق** على سكريبت 3 قبل النشر بدقيقة
3. **رسالة رد جاهزة** على كلمة (جاهز) في واتساب تفتح مسار التقييم المجاني
4. لو الـ automation مش جاهزة، أجّل نشر سكريبتات 1 و3 و4 وابدأ بـ 2 و5 (الـ CTA بتاعهم حفظ ومشاركة، مش محتاج رد)

# How to use this exemplars file (for the writing model)

These five scripts are the quality benchmark. When writing new JEDAR scripts:

1. Match the line lengths: count words per line in these scripts before writing
2. Match the beat energy curve: hot hook, rising build, confident reveal, calm payoff, warm CTA
3. Match the on-screen text density: short, synced, numbers always visible
4. Note what is ABSENT: no denial-reveal formulas, no buzzwords, no em dash,
   no client references, no stacked stats, no "الرابط في البايو"
5. The header block of each script (angle + hero proof + CTA + placement note)
   is part of the deliverable format. Include it in new scripts

## The polish history (why these lines read the way they do)

Three revisions produced this version. The lessons are binding:

- v1 failure: same stats repeated across all scripts (contaminated testing) and
  "link in bio" CTAs. Fixed by one-hero-proof rule and the soft trigger system
- v2 failure: Script 4 network beat implied covert narrative steering ("الدفة تلف

- Recordability pass: every line checked against the one-breath test and the
