# CRO-Driven Soft CTA Triggers

"الرابط في البايو" is banned. It asks the viewer to leave the video, open the
profile, hunt for a link. Highest friction, highest drop-off, zero retargeting
footprint. Every JEDAR script ends with ONE soft trigger instead.

## The trigger library

### 1. Comment keyword
- Line pattern (Gulf): "اكتب (جدار) في التعليقات... وراح يوصلك التفصيل"
- Line pattern (Egyptian): "اكتب (جدار) في الكومنتات... والتفاصيل هتوصلك"
- Why it works: lowest possible commitment + comment volume boosts algorithmic
  ranking + every commenter becomes a retargetable warm audience
- Use with: curiosity angles (secrecy, behind-the-scenes)
- Active keywords: جدار، الكواليس
- Requires: auto-reply automation LIVE before publishing

### 2. Save trigger
- Line pattern (Gulf): "هالفيديو ما تحتاجه اليوم. تحتاجه في أسوأ ليلة. احفظه من الحين"
- Line pattern (Egyptian): "الفيديو ده مش محتاجه النهارده. محتاجه في أوحش ليلة. احفظه من دلوقتي"
- Why it works: saves are the strongest distribution signal in Reels + the CTA is
  a logical extension of the angle (future need), so it lands as advice not as ask
- Use with: future-need angles (speed, educational content)
- Requires: nothing. Safe to publish anytime

### 3. WhatsApp keyword
- Line pattern (Gulf): "أرسل كلمة (جاهز) على واتساب جدار. الرقم في التعليق المثبت"
- Line pattern (Egyptian): "ابعت كلمة (جاهز) على واتساب جدار. الرقم في الكومنت المثبت"
- Why it works: a micro-commitment that opens a two-way conversation. Conversations
  close far better than website visits. Powered by a real free asset (the
  crisis-readiness assessment) so value precedes any commitment
- Use with: conversion angles (self-test)
- Active keyword: جاهز
- Requires: pinned comment with number posted BEFORE the reel goes live + a ready
  reply flow on WhatsApp

### 4. Save + send + follow (B2B combo)
- Line pattern (Gulf): "احفظ هالفيديو... وأرسله لشخص واحد يهمك مستقبل شركته. وتابع الحساب"
- Line pattern (Egyptian): "احفظ الفيديو ده... وابعته لشخص واحد يهمك مستقبل شركته. وتابع الحساب"
- Why it works: company decisions are collective. The video forwarded by a
  colleague carries built-in social proof that no direct ad can buy. The follow is
  justified by promising the next video's topic
- Use with: B2B angles (preparedness)
- Requires: the promised follow-up content must actually be planned

## CTA writing rules

1. ONE trigger per script. Never stack "save AND comment AND follow" except the
   B2B combo which is designed as a unit
2. The trigger must extend the angle's logic. A save CTA on a curiosity script
   feels bolted on; a comment CTA on a B2B script wastes the forward moment
3. The keyword goes in parentheses in the spoken line and stays fixed on screen
   for the final 5 seconds
4. Never speak the phone number or URL in the voiceover. Numbers live in the
   pinned comment
5. CTA tone: warm and direct, never shouted. It is advice from the creator, not
   a demand from the brand

## Operational checklist before publishing

1. Auto-reply automation (ManyChat / n8n / Meta native) tested on keywords جدار
   and الكواليس
2. WhatsApp reply flow for جاهز tested end to end, including handoff to the human
   team for the actual assessment
3. Pinned comment with the WhatsApp number posted within one minute of the
   self-test reel going live
4. If automation is NOT ready: publish save/share scripts first (speed,
   preparedness) and hold keyword scripts

## Publishing order and measurement

| Week | Script | CTA | Primary KPI |
|------|--------|-----|-------------|
| 1 | Secrecy | Comment: جدار | Keyword comments + auto-reply success rate |
| 1 | Speed | Save | Saves per reach |
| 2 | Behind the scenes | Comment: الكواليس | Keyword comments + profile visits |
| 2 | Self-test | WhatsApp: جاهز | WhatsApp messages + assessment conversion |
| 3 | Preparedness | Save + send + follow | Shares + follower growth |

Universal retention checkpoints for all scripts: seconds 3, 10, and 30.
A script failing at second 3 has a hook problem. Failing at 10, a build problem.
Failing at 30, the reveal came too late or too flat.
